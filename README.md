# OrganizaYa

**Tu centro productivo.**

OrganizaYa reúne tareas, calendario, proyectos, archivos y accesos rápidos en una sola aplicación web progresiva (PWA), con diseño adaptable para computadora y celular.

## Funciones principales

- Tareas con fecha, hora, prioridad, notas y subtareas.
- Calendario mensual y semanal.
- Proyectos con seguimiento visual.
- Archivos y vista previa.
- Accesos rápidos a apps y páginas.
- Avisos y notificaciones.
- Exportación e importación de respaldo.
- Sincronización opcional entre dispositivos.
- Instalación como PWA y funcionamiento sin conexión.

## Nombre internacional
